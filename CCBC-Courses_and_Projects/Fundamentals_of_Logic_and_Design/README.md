### Overview of course
* Provides an introduction to programming concepts, logic, and design used in software development
* Emphasizes problem Solving through the design and algorithms using different techniques
  * This includes flow charting, pseudocode, and functional decomposition
* Implement algorithms using a current programming language (Python)
* Topics covered include:
  * Simple data types
  * Arrays
  * Functions
  * File input/output (I/O)
  * Control structures
  * Object-oriented development concepts
