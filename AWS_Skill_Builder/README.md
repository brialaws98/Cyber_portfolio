# Course Overview
###### This course is a step towards understanding the field of AWS Cloud Security and the role that you can play as an AWS security engineer. This course is designed to provide practical, role-based knowledge.

## Key roles in AWS security
* It is a collaborative effort involving various specialties who play distinct yet complimentary roles
* Course is meant to prepare you to take on the the role of AWS security engineer
* This knowledge empowers you to see where your skills fit and how you will interact with other security professionals to achieve a common goal
* Here are some Security roles that you will encounter or work alongside in the AWS security landscape:

| Roles | Description |
|:---|:---|
| ***Could Security Analyst*** | Acts as the vigilant watchmae, constantly patrolling the fortress walls and monitoring for any signs of trouble. Their core function is to continuously monitor the cloud infrastructure for active threats and investigate suspicious activities. THey are the first responders whena security incident is detected. Analysts sift through logs, correlated event data, and use various security tools to identify potential breaches |
| ***Cloud Security Architect*** | Like the master builder or chief strategist for the fortress's security. Their primary role is to design the comprehensive security blueprint for the entire cloud environment. They are responsible for ensuring that all security measures, policies, and controls align with industry best practices in addition to regulatory requirements and the specific business objectives of the organization. Architects plan the layout of the major defensive structures, such as defining network segmentation strategies, selecting appropriate AWS services, and designing resilient identity and access management frameworks. They think holistically about security posture and risk management at a high level |
| ***Cloud Security Engineer*** | Takes architect's blueprints and bring them to life. They build, implement, and maintain the fortress's defenses. Their work involves configuring security tools and services and patching up vulnerabilities in the infrastructure and applications. They are digital locksmiths of the cloud, deeply involved in the technical implementation of security measures. |
* AWS professionals often embody a versatile blend of these responsibilities, particularly where security teams might be leaner or roles are more fluid
* This versatility requires a broad and deep understanding of AWS security and principles
